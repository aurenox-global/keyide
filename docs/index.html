Qué es

  
Un IDE completo, pensado para el móvil

  
KeyIDE nace de analizar lo que falta en los mejores editores de Android
  (Acode, Squircle IDE, DroidEdit, Spck, AIDE, CxxDroid, Pydroid) y en los entornos en la nube
  (Codespaces, Replit). Sus carencias repetidas —multi-archivo real, autocompletado, diagnósticos,
  terminal, run on-device, Git, IA— son justo lo que KeyIDE cubre.

  
Interfaz mobile-first: el editor manda y las herramientas viven en
  bottom sheets; con pantalla ancha se activa el split editor | vista previa.






  
Funciones

  
Todo lo que incluye

  

    
📝
Editor completo
Números de línea, gutter con diagnósticos, resaltado, auto-indentación y auto-cierre.

    
💡
Autocompletado
Palabras clave del lenguaje + todas las palabras del documento.

    
📑
Multi-archivo
Pestañas con buffer independiente e indicador de cambios.

    
▶️
Run real
JavaScript (V8, o Node.js con npm) y Python embebido.

    
👁️
Vista previa
WebView para HTML/CSS/JS/SVG y render de Markdown, o en split.

    
🖥️
Terminal
PTY real (apps interactivas) con fallback a sesión persistente.

    
🐞
Depurador
Puntos de parada (toque en el margen) y traza para JS y Python.

    
🎯
LSP-lite
Ir a definición, hover, referencias y renombrar símbolo.

    
🔍
Buscar y reemplazar
En el documento y en todo el proyecto, con salto a la línea.

    
🔨
Compilar
Checks .py/.js, npm install/run y build.sh.

    
🔀
Git nativo
JGit: estado, init, commit, log, pull, push y clone.

    
✨
Copiloto IA
DeepSeek, OpenAI, Claude, Qwen, Kimi, GLM o modelo local.

    
📂
Carpetas reales
SAF: abre, navega, crea y edita en cualquier carpeta.

    
🎨
Tema global
Oscuro, Claro o Sistema; idioma ES/EN; temas del editor.

    
🧩
Snippets y formato
Plantillas por lenguaje y re-indentado de documento.

    
⌨️
Atajos
Ctrl+K/S/F/B/O/P/W/Z y paleta de comandos.

Instalar

  
Descarga y listo

  

    
Descarga el APK
Desde Releases (o el .zip y descomprímelo).

    
Permite orígenes desconocidos
Ajustes → instalar apps de orígenes desconocidos.

    
Abre el APK e instala
Al abrir verás el editor con un proyecto de ejemplo.

  

  
El APK pesa ~160 MB porque incluye el intérprete de Python y Node.js (npm) para las 3 arquitecturas. Es normal en apps con runtimes embebidos.






  
Compilar

  
Desde el código fuente

  
Requisitos: JDK 17 y Android SDK 35.

  
git clone https://github.com/aurenox-global/keyide.git
cd keyide
echo "sdk.dir=/ruta/a/Android/Sdk" > local.properties
scripts/fetch-nodejs-mobile.sh   # libnode.so + npm (van en .gitignore)
./gradlew assembleRelease
